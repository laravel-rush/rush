**Rush** is an elegant CLI tool for rapidly building database schemas in your Laravel applications. It turns the routine tasks of creating migrations and models into a single, intuitive command, speeding up development many times over.

⚡️ Install your package using [Composer](https://getcomposer.org):

```bash
composer require laravel-rush/rush --dev
```
